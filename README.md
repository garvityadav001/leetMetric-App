# LeetMetric-App

A web application that fetches and displays LeetCode user statistics
in a simple and interactive dashboard.

## Features

- Search LeetCode users by username
- Display total problems solved
- Easy, Medium and Hard problem statistics
- Progress visualization
- User performance dashboard
- Responsive design

## Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- LeetCode API

## How to Run

1. Clone the repository
2. Install dependencies

npm install

3. Start the server

node server.js

4. Open the application in browser
